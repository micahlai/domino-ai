# U1: early unified product visual
- **Goal:** show real grouped workspace with Workspace/Company/Simulations navigation and simulation detail tabs before full scenario implementation.
- **Dependency:** G8 inspector audited and integrated. Sole local UI writer, no parallel UI workers.
- **Ownership:** apps/web/app/case/**, app/page.tsx CTA only, components/AppShell.tsx, components/investigate/**, new components/case-workspace/** and related tests; own Result. No historical chart internals, backend, contracts, G7 projection, dependencies/global styles.
- **Routes:** /case/2u workspace, /case/2u/company, /case/2u/simulations, /case/2u/simulations/[conversationId]. Preserve /investigate and /historical direct URLs. Reuse InvestigateLive and CompanyKnowledge/FinancialOutput; retain c/run lineage through navigation. Do not couple public case to Kestrel company ID.
- **Visual:** concise company header plus three main links; full canvas and persistent conversation on Workspace, readable evidence on Company, Overview/Impact chain/Chart/Execution tabs on detail. Real existing conversation/run data only. No fake completed scenarios; list/API or event computation pending states must explicitly say unavailable. Impact chain must not render execution dependencies as financial causation.
- **Quality:** reuse primitives, no theme work or general layout framework. Preserve node details, saved links, errors/offline states, keyboard/focus/reduced motion, mobile fit and quiet history. No technical metadata in default view.
- **Gate:** focused tests/typecheck/lint, commit then STOP. Codex fullcheck/build and actual early visual shown to user before U2 or whole redesign. No browser/provider/fullsuite by worker.
- **Skills:** orchestrator, ponytail, taste, ui-ux-pro-max. Read product-workspace spec. One process, no children.
## Result

- Routes (new, `app/case/2u/`): `/case/2u` workspace, `/company`, `/simulations`, `/simulations/[conversationId]`. A shared layout shows a concise 2U header and three links (Workspace, Company, Simulations). Links keep the open investigation: `c` on workspace/company/list, the path id on detail. `/investigate`, `/historical` and the Kestrel routes are unchanged. Landing CTA "Start investigating" now goes to `/case/2u`.
- Workspace: the existing `InvestigateLive` (canvas, persistent conversation, knowledge node, outputs) under the new shell. Shared change only: optional `place` prop `{path, newHref, id?}` on `InvestigateLive` (default is the legacy page, so behavior there is unchanged), optional `embedded` on `InvestigateWorkspace` (hides its own logo/title), `mayApplyCompletion` takes optional `path`/`pinned`, and `readConversation` is exported. No controller logic duplicated.
- Company: reads `c`, finds the baseline run from the saved forecast step, renders the existing `CompanyKnowledge` (getRun only; no getCase), plus the saved sources with publication dates and safe links. No `c` or no forecast yet: explicit empty state.
- Simulations: shows only the investigation that is open (real getConversation) and states plainly that the full list is not available yet (S2 catalog not wired). No made-up rows.
- Detail tabs: Overview (question, status in words, saved branches, assessment, steps; no IDs or method text), Impact chain (explicit "Not computed yet", says steps are order of work, not cause and effect; no S1/S3 contract exists in this tree), Chart (existing `FinancialOutput` / `HistoricalReplay` for the saved forecast, reveal or alternative; picker only when more than one exists), Execution (the existing canvas, pinned to the path id; reveal/alternative stay the existing user-driven buttons).
- No auto-run: pages only query. No mutation is called except through the existing buttons and new-question form. No provider calls. No hardcoded conversation ids or hosts. AppShell leaves `/case/*` full-window like `/investigate`. No theme, global style, dependency, lockfile, contracts, convex or projector change; `pnpm install --offline --frozen-lockfile` left the lockfile untouched.
