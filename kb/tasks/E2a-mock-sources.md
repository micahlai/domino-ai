Stable exact decimal serialization, no monetary math by agents. Observed payouts derive only from snapshot.bankTxns with Stripe evidence; future queues never read. No fabricated fee/trace linkage when legacy evidence is insufficient. Label source synthetic.

GET only, deterministic stable paging and limits, opaque validated cursors, no file-path traversal or arbitrary URL fetching, clear JSONerrors/status. Accept MOCKS_API_KEY from processenv; no authfile/envfile parsing. Read updates perrequest or documented safe reload. Start script/runbook, health route if authenticated.
