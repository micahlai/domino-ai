### Repair 1 (after candidate 594b185 crashed in the browser)
- Crash: React error 301 on `/historical`. `Session` passed a fresh inline map to `useQueries` each render; convex resubscribes on a new map and sets state during render. Fix: `useHistoricalQueries(runId, altId)` (`useMemo` on the two ids) in `HistoricalLive.tsx`; hook order unchanged.
- Error copy: `describeError` no longer says "Nothing here was changed". Unknown/network failure now says the request may or may not have been recorded, and that retry reuses the same request so it will not be saved twice. No rollback claim. The visible error and "Try again" are unchanged.
- Stale completion: `setParam` reads `window.location` at completion time, so a style chosen while a save or alternative was in flight is kept, as are other current params. Completion is dropped (no state update, no navigation) if the session unmounted, which covers leaving the page or switching baseline (`Session` is keyed by run). Request IDs and the double-click guard are unchanged.
- Invalid result: `savedRunId` throws when a save or alternative response is not `{ runId }`. `perform` then shows a visible, retryable error with the same request id, for both save and alternative. Previously the alternative stayed on "Done. Updating the page…" forever.
- Sidebar: `AppShell` shows "2U / historical" on `/historical`. Operational and demo routes keep "Kestrel Data".
- Tests: `live.test.tsx` has 2 new or changed cases (22 in file). The regression renders `useHistoricalQueries` through `renderToStaticMarkup` with a state update during render, which makes the server renderer run the component twice, and asserts the same map identity. It fails if the `useMemo` deps are made unstable (checked by mutation). Focused run passes (83 tests in `components/historical` and `lib`), `tsc --noEmit` clean, biome clean. Full suite, build and browser were not run (C0).
- Limitations: no DOM test library is installed, so the real `useQueries` loop, the `window.location` merge and the unmount guard are untested; C0's browser run should cover them (change style during a slow save, navigate away mid-save). A request ID is still not persisted across a reload, so a reload during an unknown-outcome mutation can create a second run. Activity remains unavailable; H2d is not adopted.
