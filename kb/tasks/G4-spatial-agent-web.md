# G4: a spatial agent web, not a horizontal pipeline

- **Goal:** the agent canvas visually reads as a free-form connected web around Domino, matching the user's reference direction, while preserving actual operations and edges.
- **Reference inspected by Codex:** https://www.instagram.com/reel/DdzFoJ3xybr/ opening frame: dark canvas, small circular outlined icon nodes, short labels, thin connecting lines, multiple branches spread in two dimensions. Presenter obscures part of the graph. Adopt this visual language, no claim of pixel-exact recreation.
- **Owner/files:** sole UI writer in domino-G3 after completed5d244d8. Only apps/web/components/investigate/graph.ts, InvestigateWorkspace.tsx, related presentation tests and app/playground/agent-canvas/**; this Result. Do not edit live/** (under independent audit), backend/contracts/dependencies/global styles or shared notes.
- **Design call:** Domino is a distinct central anchor; compact circular/soft-round glyph nodes with short readable labels beneath/alongside, subtle selected/focus ring, understated status. Sources, specialists, tools and outputs occupy nearby spatial clusters distributed around the anchor rather than monotonically increasing x/depth columns. Thin unobtrusive edges connect real recorded relationships. Detailed summaries/instructions remain in click details; persistent conversation remains visible.
- **Layout:** bounded deterministic radial/cluster layout using existing ReactFlow, no new physics/package. Stable incoming positions and collision separation including labels; preserve dragged positions and selection. Even a simple five-node chain should form a spatial arrangement, not a horizontal/vertical line, without inventing extra edges/nodes. Support branching/shared dependencies/disconnected/cyclic records safely. Avoid wide empty gaps or shrinking all labels to unreadable size on fit. Preserve pan/zoom and quiet reload/reduced motion.
- **Honesty:** layout changes positions only; edges/status/records stay supplied. No decorative fake satellites or manufactured agent activity. Existing result chart, profiles, evidence, keyboard focus/Enter/Escape and mobile detail/conversation behavior must survive.
- **Fixture:** add a clearly labelled manual branching web with multiple sources, specialists and outputs for visual review, preserving manual/no-timer delivery controls. Actual /investigate keeps real operations only.
- **Acceptance:** focused regression checks for new-node collision separation, retained drag/selection, restored-history quiet, actual topology preserved, lone anchor and safe empty/disconnected/cycle layout. Node text/status accessible and clickable >=44px. Codex will run serialized full suite/build and browser desktop/mobile before acceptance. No self-claimed visual pass without browser evidence.
