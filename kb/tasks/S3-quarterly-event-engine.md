## Result
- Added `quarterScenario({ bridge, baseline, scenario })` and `QUARTER_SCENARIO_METHOD` (`quarterly_event_bridge` 0.1.0) in `packages/engine/src/period-scenario.ts`, exported from `index.ts`. Hand-computed tests in `period-scenario.test.ts` (19). Existing `period.ts`, contracts, data, Convex and UI untouched.
- Baseline check: parsed with `HistoricalRunContextSchema`, then must equal the frozen bridge on branch, ID, exact cutoff string, origin, method, inputs and predictions (key order ignored). Scenario currency and target must match the case and quarter end. Nowcast and baseline predictions are carried over unchanged; event and response prediction IDs are prefixed `event_` and `response_`.
- Event: negated total outflow range, point = negated midpoint through `roundCents`, added once to total and usable (restricted unchanged). Interval length has no effect. Response: `quarterAlternative` effect added to the event branch, not recomputed. A baseline input cannot be the response. Unknown feasibility and A1's own post-hoc or hindsight status are kept; `selectedAfterReveal` taints event and response.
- Graph: event (hypothesis), baseline to event total, total to usable, and with a response: response (assumption, citing it, its dependencies and cutoff-safe basis facts), event to response total, total to usable. No rule edge, threshold, default or bankruptcy claim. Hindsight basis facts are not cited.
- Verified: engine tests for period, period-2u and period-scenario (50) pass, engine `tsc --noEmit` clean, `biome check` clean on the three files. Not run: full suite, build, browser, server, providers.
- Notes for audit: (1) the contract bars label `synthetic` on a response, so a beneficial response is a counterfactual assumption whose edge text says "Assumed, not observed"; no contract change requested. (2) `inputHash` is not recomputed here; lineage is checked by comparing `inputs` and predictions, hashing stays with S4. (3) Event and response effects are rounded separately, so a response effect can differ by 1 cent from rounding the exact combined value, as in `quarterAlternative`.
