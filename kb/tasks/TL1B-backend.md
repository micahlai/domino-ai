## Result
- Done: `timeline/baselines:save` and `timeline/baselines:get` per `kb/features/timeline/TL1-interface.md`. Save rejects `reviewed:false`, bounds and parses seed with `parseWeeklySeedJson`, recomputes the SHA-256 content hash, parses model/constraints exactly (unknown fields rejected), checks customer/bill references, safe-integer cents, ranges and repeated ids, then runs `engine.forecast` (no changes), `engine.dominoes` with explicit `{model, changes: []}`, `engine.history(26)` and `engine.pastEvents` and inserts one row. runId = `timeline:baseline/<sha256(company, requestId)[0..40]>`. Same requestId + same inputs returns the saved run (`created:false`); changed inputs -> REQUEST_CONFLICT; a different content under an already saved seed id -> SEED_CONFLICT; changed assumptions under a new requestId create a new run. Get returns only the projection, null for unknown/other-company, and never calls the engine. 25 convex-test cases: pinned Kestrel hash, tampered seed, 16 invalid inputs, real pay-by-date bill, retry/conflict/concurrency, new run with old one unchanged, seed id conflict, rollback on engine failure, zero writes to the 11 non-Timeline tables. `pnpm check` (web 492 tests, 1,635 total; lint 315 files), separate `tsc --noEmit -p convex` and lane-import inventory (18 crossings, unchanged; 0 harness) pass.
