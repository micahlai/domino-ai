## Result
- Done (Opus lead alone, no child: tables, action and tests are one coupled unit): durable conversations, receipts, messages and operations for the curated 2U case. Public `investigate`, `getConversation`, `revealInvestigation`, `requestAlternative`. Internal `runTurn`, `step`, `finishSpecialist`, `abandon`, `expireTurn`, `sourceWake`. Each mutation saves intent and schedules the work in one transaction. Claims happen once, results commit only while running and validated, and a 180 s turn deadline marks hung calls unknown with no retry. The default provider is CREAO-unavailable and fails the agent task with no call. `claude-dev` is explicit only. Specialists read the saved run's frozen snapshot at the cutoff; no reveal history. Forecast, reveal and alternative reuse the existing historical logic (bodies extracted into `saveBaselineIn`, `revealIn`, `computeAlternativeIn`; public behaviour unchanged) and store only output refs.
- API/files/checks: exact packet in `kb/coordination/historical/investigation-api.md`. Files: `apps/web/convex/investigation.ts` (new), `schema.ts` (4 additive tables), `historical.ts` (exports + extracted bodies; `loadRun` also returns `frozenCase`/`baseline`), `_generated/api.d.ts` (hand-added `investigation` module, same shape as codegen; `api.js` uses anyApi so it needs no change), `tests/investigation.test.ts` (11 tests). Agents code is imported by relative path, as `historical.ts` already does, so package.json/lock are unchanged. Passed: `vitest run convex/tests` 84/84 (all offline, fake fetch), `tsc -p convex/tsconfig.json`, `pnpm --filter @domino/web typecheck`, biome on the 4 changed source files. Not run: full `pnpm check`, build, convex codegen/dev, live backend, any provider call.
- Limits: not the full journey. CREAO coordinator/research is G2c; until then the default agent node fails `provider_unavailable`. Codegen not run (it needs a deployment). Convex bundling of `packages/agents/src` and the Claude call in the Convex runtime are untested; Codex live smoke should confirm. Follow-up questions, revealed-view specialist input, excerpts, and live or changed-source loading are not built. `sourceWake` only reports.
