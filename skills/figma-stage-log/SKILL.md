# Figma stage log

Add an entry to `kb/stage-log.md` within 10 minutes of finishing a stage. Max 200 words.

```markdown
### Stage: <Ideation | Prototyping | Handoff | Code generation> (<date time>)
- Tool(s) used and why: Figma Design / Figma Make / Figma agent / Dev Mode MCP, and the reason it fit this stage
- Minutes spent: <n>
- How well it worked (1 to 5): <n>, one sentence why
- What broke or got reworked: be specific and honest
- How the output reached the final project: file, component or commit
```

Judges reward: intentional tool choices, a traceable path from design to code, honesty about friction, and a process another team could repeat. Include a before/after where you can (for example "prototype took 20 min instead of 2 hours of code").
